# داده‌های فاز اول مسیر ج

برای بازتولید، فایل‌های اصلی تیم درس بدون تغییر در `data/raw/` قرار می‌گیرند:
`udslong_imputed.csv` (۱۲۳۷×۱۸۰)، `mriscanclean.csv` (۱۲۳۷×۱۲۶) و `combined_adjacency_matrix.csv` (۶۲×۶۲ عدد، یک ستون نام ناحیه در CSV).

اسکریپت اصلی `python src/run_phase1.py` داده‌های اصلی را فقط می‌خواند. خلاصه‌های محلی آن در `data/derived/phase1/` ایجاد می‌شوند؛ بعضی فایل‌های ممیزی در این پوشه دارای شناسه فردی‌اند، بنابراین تمام پوشه derived و raw از Git و ZIP حذف می‌شوند.

برای سوال اصلی، `CDRSUM` از UDS و ضخامت انتورینال از MRI با `NACCID` تطبیق داده می‌شوند. شاخص مشتق‌شده `ENTORHINAL_MEAN_AVGTH` متوسط ضخامت چپ و راست همان فرد است. برای ردیف‌هایی که یکی از دو ضخامت معتبر نباشد، شاخص دوطرفه معتبر محسوب نمی‌شود.

**محدودیت‌ها:** فراداده زمان اسکن/مراجعه، فرایند انتخاب زیرمجموعه، روش imputation و تایید واحد ویژگی MRI در این CSVها موجود نیستند. یک ردیف برای هر شناسه در فایل درسی به معنی تنها یک مراجعه در NACC اصلی نیست.  
راهنما: https://www.naccdata.org/the-nacc-researchers-guide
