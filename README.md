# پروژه درس آمار — مسیر ج (NACC UDS + MRI)

این مخزن شامل کدها، گزارش‌ها و خروجی‌های تجمیعی **فاز اول و فاز دوم** پروژه مسیر ج است. تحلیل‌ها بر زیرمجموعه ازپیش‌آماده‌شده تیم درس انجام می‌شوند؛ نتایج به کل پایگاه NACC یا جمعیت عمومی تعمیم داده نمی‌شوند.

## ۱. داده‌های موردنیاز

فایل‌های اصلی تیم درس را بدون هیچ تغییری و فقط روی سیستم شخصی در مسیر `data/raw/` قرار بده:

- `udslong_imputed.csv`
- `mriscanclean.csv`
- `combined_adjacency_matrix.csv` (برای اجرای فاز اول)

فاز دوم فقط به دو فایل UDS و MRI نیاز دارد؛ فایل ماتریس مجاورت در اجرای فاز دوم استفاده نمی‌شود.

**محدودیت نگهداری و انتشار:** فایل‌های خام و خروجی‌های ریزدانه‌ای که شناسه `NACCID` یا ردیف‌های فردی دارند نباید در GitHub یا ZIP تحویل قرار بگیرند. به‌ویژه پوشه `data/derived/phase1/` ممکن است شامل خروجی‌های فردمحور باشد و باید محلی باقی بماند. توضیحات بیشتر در `data/README.md` آمده است.

## ۲. نصب و اجرای پروژه

دستورها را از ریشه پروژه و در محیط مجازی Python اجرا کن. در PowerShell ویندوز:

```powershell
python -m pip install -r requirements.txt
python src/run_phase1.py
python src/run_phase2.py
```

هر اجرا فقط اسکریپت‌های همان فاز را اجرا می‌کند. فایل‌های خام فقط خوانده می‌شوند و تغییر داده نمی‌شوند. اگر `XeLaTeX` نصب باشد، هر runner فایل PDF گزارش همان فاز را با دو بار کامپایل به‌روزرسانی می‌کند؛ در غیر این صورت فایل `.tex` ساخته یا به‌روزرسانی می‌شود و PDF موجود دست‌نخورده می‌ماند.

```powershell
python src/run_phase2.py
```

فاز دوم فایل‌های خروجی فاز اول را بازنویسی نمی‌کند و برای محاسبات خود آن‌ها را نمی‌خواند؛ بااین‌حال، آستانه رویداد MRI یعنی `3.0575` همان میانه محاسبه‌شده در فاز اول است و کد فاز دوم ثابت‌بودن این مقدار را با داده‌های ورودی کنترل می‌کند. مرحله دوم فاز دوم از خروجی‌های تجمیعی مرحله اول فاز دوم استفاده می‌کند و نتایج آن‌ها را با بازبینی داده خام کنترل می‌کند. مرحله سوم فاز دوم محاسبات توزیع و کوواریانس را مستقیماً از فایل‌های خام UDS و MRI انجام می‌دهد. سازنده گزارش، خروجی‌های تجمیعی مراحل فاز دوم را برای درج در گزارش می‌خواند.

## ۵. تعریف‌ها و قراردادهای آماری فاز دوم

- **واحد تحلیل:** یک ردیف ارائه‌شده برای هر `NACCID` در فایل UDS و یک ردیف برای همان شناسه در فایل MRI. کدها وجود، یکتایی و تطابق شناسه‌ها و اتصال یک‌به‌یک را کنترل می‌کنند. یک ردیف در فایل‌های تحویلی، به معنی یک مراجعه واقعی در کل سابقه NACC نیست.
- **رویداد A:** `NACCUDSD == 4`؛ یعنی وضعیت دمانس طبق متغیر وضعیت شناختی UDS. این تعریف به‌تنهایی دمانس ناشی از آلزایمر را مشخص نمی‌کند.
- **رویداد B:** `ENTORHINAL_MEAN_AVGTH < 3.0575`؛ شاخص ضخامت دوطرفه برابر میانگین `LH_ENTORHINAL_AVGTH` و `RH_ENTORHINAL_AVGTH` است. آستانه ۳٫۰۵۷۵ میانه فاز اول و صرفاً یک آستانه توصیفی برای تقسیم گروه‌هاست، نه نقطه برش بالینی.
- **احتمال‌های شرطی:** فقط دو احتمال شرطی مربوط به دو گروه MRI، یعنی `P(A | B)` و `P(A | NOT B)`، گزارش می‌شوند. مقدار `P(B | A)` فقط به‌عنوان مقدار میانی در محاسبه قضیه بیز استفاده می‌شود.
- **مدل دوجمله‌ای:** تابع جرم احتمال کامل برای `k = 0, ..., 10` در مدل نظری `Binomial(n=10, p)` گزارش می‌شود؛ `p` برابر احتمال تجربی رویداد A در زیرمجموعه است. این مدل یک مثال نظری با ۱۰ انتخاب مستقل فرضی است، نه نمونه‌ای از ۱۰ شرکت‌کننده واقعی، نمونه‌گیری بدون جایگذاری یا Bootstrap.
- **توزیع و گشتاورها:** واریانس‌های تجربی و کوواریانس با مخرج `N` محاسبه می‌شوند. انحراف معیار نمونه‌ای نیز برای پیوستگی با فاز اول گزارش می‌شود. چولگی فقط شاخصی توصیفی است و آستانه‌ای برای طبقه‌بندی بر اساس آن اعمال نمی‌شود.
- **داده‌های پرت:** مقادیر پرت بر اساس قاعده IQR پرچم‌گذاری می‌شوند و از محاسبات حذف نمی‌شوند.
- **محدوده تحلیل:** آزمون فرض، آزمون رسمی نرمال‌بودن، `P-value`، همبستگی، رگرسیون، Bootstrap و فاصله اطمینان در فاز دوم انجام نمی‌شوند. نمودار Q-Q و منحنی نرمال صرفاً برای مقایسه بصری توزیع استفاده می‌شوند.
- **محدودیت مراجعه و اسکن:** وجود فیلدهای مرتبط با مراجعه یا تاریخ اسکن در فایل‌های ارائه‌شده بررسی و ثبت می‌شود؛ اما اطلاعات موجود برای بازسازی قاعده انتخاب اولین، آخرین یا نزدیک‌ترین مراجعه UDS به MRI کافی نیست. بنابراین تحلیل، تاریخچه مراجعات NACC را بازسازی نمی‌کند.

## ۷. محدودیت‌های تفسیری پروژه

- داده‌ها زیرمجموعه‌ای ازپیش‌آماده‌شده از NACC هستند و نمونه‌گیری احتمالی قابل تعمیم به جمعیت عمومی محسوب نمی‌شوند.
- فایل UDS از پیش `imputed` است؛ درصد گمشدگی اولیه و جزئیات روش جایگذاری از فایل موجود قابل بازیابی نیست.
- تاریخ MRI و UDS و نسخه فرم `FORMVER` در زیرمجموعه موجود نیستند؛ هم‌زمانی MRI و ارزیابی بالینی و قاعده انتخاب مراجعه قابل تأیید نیست.
- همه افراد زیرمجموعه تحویلی MRI دارند؛ بنابراین مقایسه افراد دارای MRI و فاقد MRI در این داده ممکن نیست.
- `NACCUDSD` وضعیت شناختی را نشان می‌دهد و به‌تنهایی تشخیص علت‌شناختی آلزایمر نیست.
- نتایج، توصیف و تحلیل همین زیرمجموعه‌اند و نباید به‌صورت رابطه علّی یا نتیجه‌ای درباره کل جمعیت تفسیر شوند.
